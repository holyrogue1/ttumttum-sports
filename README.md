# 틈틈이

혼자·둘이·아이와 보호자가 공공체육시설 수영 강좌의 시간과 잔여석을 비교하는 공모전 시연입니다. `dist/index.html`이 진입점입니다. 정적 서버 없이 브라우저에서 바로 열 수 있습니다.

## 데이터와 기준

기관 공공데이터 15147992의 올림픽수영장과 일산올림픽스포츠센터 수영 프로그램을 공식 등록현황과 연결했습니다. 화면은 2026년 11월 25일 확인한 12월 분 21건을 사용합니다. 정원과 잔여석은 당시 공식 조회 값입니다. 공개 강좌 21건을 시간대별로 집계하므로 실제 이용 인원이나 전체 수강 현황을 나타내지 않습니다.

일산의 일부 성인 강좌에 포함된 토·일 자유수영 혜택일은 필수 수업 요일에서 제외했습니다. 가족 비교는 올림픽수영장의 공식 일일 헬스 영업시간을 기준으로 합니다. 당일 헬스 입장과 수영반 신청은 센터의 공식 안내에 따릅니다.

## 데이터 정리

시연 스냅샷은 `dist/data.js`에 있습니다. 공공데이터포털 CSV와 두 센터의 공식 수영 등록현황 HTML 원본을 보관한 폴더를 준비한 뒤 다음과 같이 스냅샷을 재생성합니다. 작성 당시 파일 이름은 `courses-20260825.csv`, `dec-olympic.html`, `dec-ilsan.html`입니다. 새로운 수강월을 만들 때는 확인일, HTML의 표시 문구, 신청 전에 확인한 강좌 목록을 함께 갱신합니다.

```sh
python scripts/build_snapshot.py <공식 원본 폴더> dist/data.js
```

데이터 추출 스크립트는 Python과 lxml을 사용합니다. 웹 구동에는 별도 설치가 필요 없습니다. 검색 조건은 현재 페이지 안에서만 처리합니다.

마스코트는 공모전 시연용으로 제작한 두루미 이미지입니다. Spoqa Han Sans Neo의 라이선스는 `dist/spoqa-OFL.txt`에 포함되어 있습니다.
